# meta-state

THIS IS GENERATED DATA THAT THE SYSTEM USES INTERNALLY.

NEVER MODIFY ANYTHING IN THIS DIRECTORY MANUALLY.

## The one exception: `aliases.txt`

`aliases.txt` is a pool of memorable names for machines, one per line,
and it is seeded and refilled BY HAND (stage 59). The rule is a division
of bytes, not of files: **a human only ever APPENDS lines; the system only
ever comments out lines that are already there**, in place, with what took
the name and when. Never edit or reorder a line the system commented out,
and never uncomment one: a name is spent exactly once.
